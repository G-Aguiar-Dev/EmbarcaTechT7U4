# EmbarcaTechT7U4
Projeto realizado de acordo as instruções da atividade referente ao Capítulo 7 da Unidade 4. Esta referência se aplica ao programa de capacitação EmbarcaTech - TIC 37

# Vídeo Explicativo

https://youtube.com/shorts/UIxiaJS3B4c

# instruções

O programa utiliza PWM para variação de sinal em um pino GPIO.<br>
Em ambiente de simulador, utilizando-se da extensão do Visual Studio Code Wokwi, a variação é demonstrada em um servomotor. <br>
Para utilizar a simulação deve-se definir a variável SERVO_PIN em 22. Caso queira utilizar o LED da placa BitDogLab, deve-se definir a variável em 11, 12 ou 13.
